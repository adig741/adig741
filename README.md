## Featured project: BrightNet

BrightNet is my final engineering project at Shenkar College: a prototype for bidirectional data communication through visible light. The work connects a lamp and a dongle through an optical link, with FPGA firmware at both ends and Windows and Android tools for control and diagnostics.

| Layer | What I built and documented |
| --- | --- |
| Digital hardware | DECA MAX 10 and DE0 Cyclone III FPGA endpoints, framing, CRC, and host interfaces |
| Optical and physical design | LED transmitter, lens and photodiode receiver, alignment, and enclosure models |
| Software | Windows Universal Console and Android companion app for communication and testing |
| Engineering record | Schematics, design iterations, simulations, release files, and validation notes |

The [BrightNet project page](https://github.com/adig741/BrightNet-Optical-Network) includes a system diagram and selected interface screenshots. The [Projects page and board](https://github.com/users/adig741/projects/2/views/1?pane=info) organize the documented work and open verification steps. Sign in to the owning account to browse [the private engineering archive](https://github.com/adig741/BrightNet-Project-Archive), including source and final deliverables. Older drafts and generated files are in [seven downloadable archive volumes](https://github.com/adig741/BrightNet-Project-Archive/tree/main/11_Historical_Backup), so they do not appear as individual files in GitHub.

## Arduino Tic-Tac-Toe

An earlier Programming 1 project by Faraj Kharbaoui and me: a two-player Tic-Tac-Toe game on an Arduino Mega 2560 with an Elegoo touch display and buzzer. The sketch handles touch input, turns, win and tie detection, and sound feedback. The project page includes photos, a video, and a playable browser version of the game.

[Explore the project page](https://adig741.github.io/arduino-tic-tac-toe-touchscreen/) · [Source and setup](https://github.com/adig741/arduino-tic-tac-toe-touchscreen)
